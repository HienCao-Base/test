Workflow automation

n8n: tự động hoá công việc bằng cách nối các node

n8n (đọc là "n-eight-n") là công cụ tự động hoá quy trình. Bạn kéo thả các khối (node) và nối chúng thành một workflow, để các ứng dụng tự trao đổi dữ liệu với nhau mà không cần làm tay.

Vì sao nhiều người chọn n8n

n8n nằm giữa các công cụ no-code dễ dùng và việc tự viết code từ đầu.

1

Kéo thả trực quan

Dựng workflow trên giao diện sơ đồ, nhìn rõ dữ liệu đi qua từng bước.

2

Tự host được

Cài trên máy chủ của mình để giữ dữ liệu nội bộ, hoặc dùng bản n8n Cloud.

3

Viết code khi cần

Node Code cho phép chèn JavaScript hoặc Python để xử lý những chỗ phức tạp.

4

Nhiều tích hợp sẵn

Có sẵn node cho hàng trăm dịch vụ phổ biến; dịch vụ nào chưa có thì gọi qua HTTP Request.

5

Làm AI agent

Có các node AI để nối mô hình ngôn ngữ, bộ nhớ và công cụ thành một agent.

Các khái niệm cơ bản

WorkflowMột chuỗi các bước tự động, chạy từ trái sang phải.
NodeMột bước trong workflow: đọc dữ liệu, xử lý, hoặc gửi đi đâu đó.
TriggerNode khởi động workflow: theo lịch, khi có webhook gọi tới, khi có email hay form mới…
CredentialsThông tin đăng nhập vào các dịch vụ (API key, OAuth), lưu riêng và dùng lại được.
ExecutionMột lần workflow chạy. Xem lại được để biết node nào lỗi và dữ liệu ra sao.
ExpressionCú pháp {{ $json.ten_truong }} để lấy dữ liệu từ node trước.

Bắt đầu nhanh

Cách đơn giản nhất để thử trên máy cá nhân là chạy bằng Docker:

docker run -it --rm --name n8n -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
  1. Mở trình duyệt tại http://localhost:5678 và tạo tài khoản chủ sở hữu.
  2. Bấm tạo workflow mới, thêm một node Trigger (ví dụ Schedule hoặc Manual).
  3. Thêm các node tiếp theo, kết nối credentials của dịch vụ cần dùng.
  4. Bấm chạy thử, xem dữ liệu ở từng node, rồi bật Active để workflow tự chạy.

Lưu ý

Giấy phép

n8n dùng mô hình "fair-code": xem được mã nguồn và tự host miễn phí cho nhu cầu nội bộ, nhưng có giới hạn khi dùng để kinh doanh lại.

Bảo mật

Khi tự host, hãy đặt sau HTTPS, bảo vệ webhook và sao lưu thư mục dữ liệu định kỳ.

Theo dõi lỗi

Dùng Error Workflow để nhận thông báo khi một workflow chạy thất bại.

Tìm hiểu thêm tại n8n.io và docs.n8n.io.
